# Documentación del Proyecto Mercapleno

## Descripción

Este repositorio contiene la documentación completa del proyecto **Mercapleno**. Se trata de un proyecto estructurado por trimestres académicos con el objetivo de documentar el desarrollo, planificación y resultados de las diferentes fases del proyecto.

## Estructura del Repositorio
Doc_mercapleno/ 
├── Primer_Trimestre/ 
│ └── [Documentación del primer trimestre] 
└── Segundo_Trimestre/ 
    └── [Documentación del segundo trimestre]


### Directorios Principales

- **Primer_Trimestre**: Contiene toda la documentación correspondiente al primer trimestre del proyecto, incluyendo planificación inicial, requisitos, análisis y primeras implementaciones.

- **Segundo_Trimestre**: Alberga la documentación del segundo trimestre, con actualizaciones, avances, cambios y nuevas funcionalidades implementadas.

## Contenido Esperado

En cada directorio trimestral encontrarás:

- Documentos de planificación y especificaciones
- Análisis de requisitos
- Reportes de progreso
- Diagramas y arquitectura
- Resultados y conclusiones del trimestre

## Propósito

Este repositorio sirve como centralización de toda la documentación del proyecto Mercapleno, facilitando el seguimiento del progreso, la evaluación de hitos y la referencia histórica de decisiones tomadas durante el desarrollo.

## Cómo Utilizar

1. Navega por los directorios trimestrales para consultar la documentación específica
2. Revisa los documentos de cada fase para entender el contexto y evolución del proyecto
3. Utiliza los reportes para evaluar el progreso y cumplimiento de objetivos

## Contribuidores

Este proyecto es mantenido por el equipo de desarrollo de Mercapleno.
